# Расходник

Личный журнал расходов на Go и SQLite: регистрация, вход, CRUD, категории,
фильтры по датам, сортировка, сводка, графики Chart.js и выгрузка CSV.
Каждый пользователь работает только со своими записями.

## Запуск

Требуется Go 1.26+; проверено на Go 1.27.2. Компилятор C не нужен.

1. Скопируйте `.env.example` в `.env` в корне проекта.
2. Замените `SESSION_SECRET` случайным секретом длиной от 32 байт.
   Сгенерировать его в PowerShell можно так:

   ```powershell
   $bytes = New-Object byte[] 32
   $rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
   $rng.GetBytes($bytes)
   [Convert]::ToBase64String($bytes)
   $rng.Dispose()
   ```

3. Запустите приложение:

   ```sh
   go run .
   ```

Откройте http://localhost:8081, создайте аккаунт и войдите. Остановка — Ctrl+C.
Также поддерживается `go run ./cmd/expenses`. Миграции применяются автоматически;
новая SQLite-база создаётся при первом запуске. Шаблоны и статические файлы встроены.

| Настройка | Назначение |
| --- | --- |
| `PORT` | Обязательный порт сервера; в примере 8081 |
| `DB_PATH` | Обязательный путь к SQLite; родительская папка должна существовать |
| `SESSION_SECRET` | Случайный секрет от 32 байт; при смене требуется повторный вход |
| `COOKIE_SECURE` | `false` для локального HTTP, `true` для HTTPS |
| `SESSION_TTL` | Длительность сессии: от `1m` до `720h`, по умолчанию `168h` |

Окружение имеет приоритет над `.env`. Для публикации нужен HTTPS через обратный
прокси и `COOKIE_SECURE=true`. Ограничитель входа рассчитан на один процесс.
Секреты и файлы базы исключены из Git.

Расходы хранятся в копейках. CSV: UTF-8 с BOM, разделитель `;`, защита текстовых
ячеек от формул. Выгрузка выборки сохраняет фильтры и сортировку.
Диаграммы загружают Chart.js с CDN; при недоступном CDN остаются таблицы статистики.

## Проверка

```sh
go test ./...
go vet ./...
go build ./...
```

Тесты проверяют CRUD, изоляцию пользователей, сессии, CSRF, валидацию, фильтры,
сортировку, сводку, статистику, CSV, сохранение после перезапуска и ошибки хранилища.
